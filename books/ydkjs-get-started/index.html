You Don't Know JS Yet: Get Started (2nd Edition)

"Knowing JS is not a destination, it's a direction."
— Kyle Simpson (@getify)

Quick Overview

  • Book: You Don't Know JS Yet: Get Started (2nd Edition)
  • Author: Kyle Simpson
  • Core Goal: Build an accurate, deep mental model of JavaScript's real mechanics without unnecessary academic jargon.

Chapter Roadmap

  • Chapter 1: What Is JavaScript?
    The 1995 naming marketing trick, TC39 & ECMAScript standard, backwards compatibility guarantee, why JS is a compiled language, and Babel/Polyfills.

  • Chapter 2: Surveying JS
    Primitives vs Objects, typeof quirks, var vs let vs const, strict === vs coercive ==, reference comparisons, and Classes vs Modules.

  • Chapter 3: Digging to the Roots of JS
    The core engine of JavaScript: Iterators & for..of, Closures (the backpack analogy), the this keyword demystified, and Prototype Delegation.

  • Chapter 4: The Bigger Picture
    The 3 Pillars of JavaScript (Scope/Closure, Prototypes, Types/Coercion), writing code "with the grain", and the 6-book series roadmap.

  • Appendix: Practice Challenges & Solutions
    Deep dives into value vs. reference copies, plus 3 hands-on code challenges (scheduleMeeting, range, and the slotMachine with prototypes).
